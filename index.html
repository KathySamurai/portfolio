自己紹介

10年ほど前に第2子の出産を期に、東京から福岡に移住しました。趣味のボルダリングをし、真っ白な文鳥を飼い、5時半には起き、22時すぎには寝ています。2人の育児は難しく、いつまで経ってもうまくできませんが・・・そのこと自体を楽しめてる日々に感謝です。

30歳まで漫画家を目指しつつ、アルバイトや日雇いでつないでいました。夢を諦めたことがきっかけで、ちゃんと学びたいと思って Web に入りました。フロントエンドの実装から始まって、PHP と Laravel で実装を積み、テックリードも経験しています。使いやすい、使いたくなるプロダクトを作りたいと思って、UI/UX などのデザインの側に寄っていきました。

早さが大切ということは理解しつつ、それによって失われる可能性も見てきた気がします。無駄を省き、やるべきことを最大限丁寧にやる。1人でできることなんて限られているので、関わる人の凸凹を楽しみ、力に変えるようなそんな働き方、関わり方をしたいと思っています。

大切にしたいこと

価値を届ける

何事も伝わらなければ意味がないと思っています。作ることを目的にするのではなく、届け、さらにはその先も想像したプロダクト作りをしたいと思っています。

意図をもつ

これからも多くを学び続けるためには意図が必要と考えています。実装もしかり、デザインもしかり、ひいては色やフォント、角丸の角度など細部まで、意図をもってやりたいと思います。

人を見る

すぐさま反応するのではなく、1つの人生として見ることで色々なものが見えるのかなと思います。メッセージの向こうには人がいて人生があると思うと、応援したくなるし、お節介を焼きたくなる。そうやって人と関わっていきたいです。

楽しむ

楽しくないと続きません。続かないと結果も出ません。ただ、結果は指標で、過程があればこそでもあります。失敗や怒りすらも楽しめるようになりたいです。

お恥ずかしい話ではありますが、スケジュール管理を1人でするのが苦手です。作業が問題というより、始めるまでが問題かと。相談できる相手や、定期的に話すことで力を大いに発揮するタイプかなと思います（笑）

技術

現在 Flutter / Flutter Web。サービスデザインから UI/UX、実装まで。Cursor による AI 開発。
バックエンド PHP / Laravel（10年以上）。要件定義・詳細設計・仕様折衝〜実装やサーバー構築まで。toC、toB、API など。
フロント HTML / CSS / JS（10年以上）。Vue / Nuxt。toB 向けが多い。
インフラ AWS と GCP。構築、ミドルウェア、パフォーマンス、セキュリティやデプロイ自動化・CI まで。
デザイン UI/UX。Figma / Adobe XD。ユーザーインタビューからプロダクトへの落とし込み。
その他 MySQL、PostgreSQL、Rails（小規模実装と移管）、Perl（横展開基盤）

役に立てるなら、エンジニアリングでも UI/UX でも、そのあいだでも引き受けます。
