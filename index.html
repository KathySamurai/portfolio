自己紹介

福岡在住の2児の父です。ボルダリングが好きで、文鳥を飼っていて、そのお世話もあって朝は5時半には起き、夜は10時すぎには寝ています。

30歳手前までは飲食や現場の仕事などをしていて、そこから未経験で Web に入りました。PHP と Laravel で実装を積み、テックリードを経験したあとデザインの側にも寄っていき、いまは業務委託として、要件を取り込むかどうかの判断から UI と実装までを一人で見ています。まっすぐ来たキャリアではないので、人の話はできるだけ最後まで聞くようにしていて、短絡的に聞こえることでも、その人の意図を想像しながら補って受け取りたいと思っています。今できることはそのときの環境で違うので、それを能力の結論にはせず、それでも違うと感じたときは相手を下げずに伝えるようにしています。

判断するときは、動くかどうかより、使われるか、あとから保守しやすいか、今の納期と予算に対して量として適切かを見ていて、分からないことは手を動かさないと分からないので、まず小さくやってみることが多いです。仕事を選ぶときも、一緒にいる人の人柄と、自分が当事者になれるかを大切にしていて、規模が必要なプロダクトもあるとは思いながら、そうでないものまで無理に大きくしなくてもいい、というのが今の気持ちです。

大切にしていること

敬意を先に置く

人として、先に敬意を置きたいと思っています。話が雑に聞こえても意図を補って聞くようにしていて、違うと思ったときは直接伝えます。高圧的な現場からは、静かに離れました。

必要な量を考える

安易な実装は避けて、あとで誰が保守するのか、本当に使われるのかを先に考えるようにしています。見当がつかないときは小さく始めて、納期と予算の範囲で必要なところまでにとどめます。

実装から体験まで

最初から得意分野があったわけではなく、サーバー、フロント、決済、CMS など広く触ってきました。デザインのマーケやブランドは、本やポッドキャストで追っています。深くないことは、深くないと言います。

人とチームが続くか

売上や規模が、いつも最優先だとは思っていません。規模が必要なプロダクトもありますが、らくばるはそうではありません。無理な拡大でチームが傷つく様子は、リトル・ママ、エール、ザッパラスで見てきました。

気持ちが乗らないと着手が遅れがちで、一人作業は向いている一方、放置されるとスケジュールが雑になります。相談できる人がいると立て直しやすいです。

技術

バックエンド PHP / Laravel（10年以上）。詳細仕様のない状態からの設計〜実装。管理画面、API、分析、通知、PDF 出力。
フロント HTML / CSS / JS（10年以上）。Vue / Nuxt。WordPress カスタマイズから、案件ごとに表だけ差し替える横展開まで。
いま Flutter / Flutter Web。サービスデザインから UI、実装まで一人。Cursor による AI 開発。
インフラ AWS と GCP。構築、ミドルウェア、パフォーマンス、セキュリティ。らくばると自作の診断アプリは GCP。ユーザー情報の扱いなど、元エンジニアとしての指摘。
デザイン UI/UX。Figma / Adobe XD。ユーザーインタビューからプロダクトへの落とし込み。エンジニアが実装しやすい定義への整理。
その他 MySQL、Rails（小規模実装と移管）、Perl（横展開基盤）

役に立てるなら、エンジニアリングでも UI/UX でも、そのあいだでも引き受けます。
