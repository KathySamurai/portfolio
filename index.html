ENGINEER / PRODUCT DESIGNER

真面目に、単刀直入に、
丁寧につくる。

志のある人の実現を、エンジニアリングと UI/UX で助けたい。肩書きより、プロダクトの手助けになるかどうか。

Yoshinori Ito 福岡市 基本情報技術者

概要

30歳手前で未経験から Web エンジニアへ転身し、PHP / Laravel を軸に実装を積み、テックリードを経てプロダクトデザイナーへ自ら転向しました。いまは業務委託で、サービスデザインから UI、実装までを一人で担っています。

大きなシステムの一人開発と、少人数の 0→1、既存デザインを引き継いでの PoC 支援の両方があります。判断の基準は「動くこと」ではなく「使われること」。取り込むか、取り込まないかまで含めてプロダクトに落とします。

仕事選びの軸は、人柄と、自分が当事者になれるかどうかです。論理的で思慮深い人とは、本質と現実の話ができます。丁寧にできないものは、そもそも不要だと思っています。

強み

丁寧に、細部まで

雑にしかできないものは不要だと考えています。一人で大きな人材開発システムを設計から実装まで持ち、後任の保守担当にもコードを評価されました。シンプルでも、完成度は落とさない。

単刀直入で、知らないことは知らないと言う

正直さが信頼になると、最初の現場で知りました。合わない状況でも早めに伝え、必要な支援を得てやり切る。思っても言えない、動けない人が多いなかで、実行して実績を出すことを残してきました。

使われることを正にする

機能面では動くことが正、体験面では使われることが正。要件をそのまま実装するのではなく、サービスデザインの段階から取捨します。腹落ちしないまま進む危うさは、自分でも経験しています。

実装とデザインのあいだを翻訳する

エンジニアが読める定義にデザインを落とすこと、仕様変更に合わせて UI を作り直すことが得意です。役職を超えた 1on1 で間をとりもち、つなぐ役にもなりやすいです。

癖もあります。気持ちが乗るまで手がつかない。一人作業は性に合いますが、放置されるとスケジュールが雑になる。着手さえすれば進み、相談できる相手がいると立て直せます。

技術

バックエンド PHP / Laravel（10年以上）。詳細仕様のない状態からの設計〜実装。管理画面、API、分析、通知、PDF 出力。
フロント HTML / CSS / JS（10年以上）。Vue / Nuxt。WordPress カスタマイズから、案件ごとに表だけ差し替える横展開まで。
いま Flutter / Flutter Web。サービスデザインから UI、実装まで一人。Cursor による AI 開発。
インフラ AWS と GCP。構築、ミドルウェア、パフォーマンス、セキュリティ。らくばると自作の診断アプリは GCP。ユーザー情報の保持など、元エンジニアとしての指摘。
デザイン UI/UX。Figma / Adobe XD。ユーザーインタビューからプロダクトへの落とし込み。エンジニアが実装しやすい定義への翻訳。
その他 MySQL、Rails（小規模実装と移管）、Perl（横展開基盤）

肩書きへのこだわりはありません。役に立つならエンジニアリングでも UI/UX でも、そのあいだでもやります。
